# DeepSeek-V4.1-Flash v5.5.0 Radiance Wave 8 Ports & Paired Benchmark Report

**Date**: 2026-11-22  
**Hardware Platform**: Dual AMD Radeon AI PRO R9700 (`gfx1201`, RDNA 4, Wave32, TP=2, 2 × 32 GiB), Dual Intel Xeon Platinum 8160 (48 cores / 96 threads, pinned `--cpuset-cpus=0-23,48-71`), PCIe 3.0 x16  
**Baseline Arm**: `deepseek-affinity:v5.4.0` (ROCm `10.1.0-full`)  
**Release Candidate**: `deepseek-affinity:v5.5.0-rc1` / `v5.5.0` (`55de363`, ROCm `10.1.0-full`)  
**Model & Runtime Flags**: `DeepSeek-V4.1-Flash-1017-MoonMath` (`model-moonmath-1017.aff`, `--dspark on`, `--engram`, `--kv-size 327680 --kv-commit 262144`, `--prefill-chunk-size 2816`, `--placement-strategy demand`, `--host-pool-mib 200000`, `--default-effort 60`)

## 1. Executive Summary

`v5.5.0` (Wave 8) ports seven targeted RDNA 4 (`gfx1201`) and speculative-decoding optimizations (`R1–R7`) from Radiance onto the stabilized `v5.4.0` baseline without changing target model numerics (`-ffp-contract=off`, bit-exact BF16 target LM head, prefix-cache fingerprint `0x733de762fee543e6` preserved):

- **Warm Decode Gains (`+25.5%` to `+43.1%` `tg2` across 4K–64K & `code_edit`)**: In the Stage B2 paired `v5.4.0` vs `v5.5.0-rc1` benchmark, warm Pass-2 decode (`tg2`) rises across every depth and workload:
  - `l4k`: `34.40 -> 43.16 tok/s` (**`+25.5%`**)
  - `l16k`: `33.77 -> 44.55 tok/s` (**`+31.9%`**)
  - `l64k`: `32.08 -> 43.70 tok/s` (**`+36.2%`**)
  - `code_edit`: `28.15 -> 40.27 tok/s` (**`+43.1%`**)
- **4-Prompt `temp=0.0` DSpark & `80K -> 123K` Multi-Turn**: 4-prompt DSpark streaming improves **`+0.4%` to `+15.3%`** across prompts, while `80K -> 123K` multi-turn decode advances **`+45.9%` on `turn3`** and **`+43.6%` on `turn4`**.
- **+24 Resident MoE Experts (`3,593 -> 3,617`)**: Lossless 12.25-bit `bf16x12` target LM head packing (`R5`, `AFF_LMHEAD_BF16X12=1`) reclaims output-plane VRAM without losing bit-exact BF16 weight fidelity, expanding live GPU-resident MoE capacity from `3,593` to **`3,617` experts**.
- **Clean ELF / ISA & Test Verification**: All **`599`** compiled `gfx1201` kernels report **`0` static scratch bytes** and **`0` VGPR spills**, **`11/11` CPU `ctest`** and **`5/5` GPU binaries** PASS, fallback-OFF toggle coverage + **`64/64` static-placement parity** PASS, `DRY` verbatim protection passes **`3/3`**, `</think>` checkpoint restores **`653/653`** tokens, `64`-block (`33,792`-tok) stride checkpointing is verified at `64K` and `80K`, and clean KFD release completes in **`3.298 s`**.
- **Evidence-Gated Defaults**: Ablations lock `R1`, `R3`, `R4`, `R5`, and `R6` ON by default, while locking `R2` (`AFF_TP_AR_CODED=0`, `-54.8%` KL vs FP32 at `~2.5%` 64K PP cost) and `R7` (`AFF_PREFETCH_BESIDE=0`, `-15.5%` to `-33.2%` regression) opt-in.

### 2.1 Port-by-Port Architecture Summary (`R1–R7`)

1. **`R1` — Pure-LDS Workgroup Barriers & Store-Wait/Agent Fences (`e9279b1`, always ON)**:
   Replaced global-draining `__syncthreads()` and redundant `__threadfence()` calls with `aff::lds_barrier()`, inline `s_wait_storecnt 0x0`, and `__ATOMIC_RELEASE`/`__ATOMIC_ACQUIRE` (`__HIP_MEMORY_SCOPE_AGENT`) barriers across `indexer_gpu.hip` (`hist_scan`, `compact_row`, `compact_admitted`, `idx_topk_mask_kernel`, `idx_topk_hist_kernel`, `idx_topk_tie_kernel`, `idx_rope_qat_kernel`), `batch_kernels.hip` (`gemm_fp8_body`, `batch_argmax_kernel`, `markov_step_kernel`, `hc_role_wait`, `hc_read_fused_v2_kernel`, `hc_chained_decode_kernel`), `digest.hip`, `dense_gpu.hip` (`hc_apply_mg2_kernel`), and `tp_allreduce.hip`.

2. **`R2` — Lossless 12.125-bit Exponent-Delta Coded BF16 TP=2 All-Reduce (`e9279b1`, `AFF_TP_AR_CODED=0` default opt-in)**:
   Added `TpReduce::Coded` (`tp_ar_coded_kernel`, `tp_ar_coded_staged_kernel`, `r4d_arc_enc`/`r4d_arc_dec` across 8 Wave32 lanes via `ds_bpermute`) encoding 64-element groups into `96 B` packed codes + `1 B` `base_exp`, with `0xFF` raw 128 B BF16 fallback for subnormals, `±Inf/NaN`, or exponent span `> 14`. Controlled via `AFF_TP_AR_CODED` (`0` default) or `AFF_TP_AR_MODE=coded|fp8|exact`.

3. **`R3` — Register-Form Fused AR+HC Expand & Early Wake Store (`e9279b1`, default ON)**:
   `AFF_AR_REG_FORM=1` (default) caches up to `kRegCap = 12` local `block` values per thread in VGPRs across the peer barrier in `tp_ar_batch_hc_expand_kernel` and `tp_ar_kernel`, eliminating redundant global `block` re-reads after peer arrival. `AFF_AR_WAKE_STORE=1` (default) posts peer wake stores (`kTpArFlagWakeEarly`) at kernel entry before `seq_ctrs` atomic increments (`AFF_AR_FAST_REL=0` default preserves release flag ordering).

4. **`R4` — Pre-Collapsed AR + V4.1 RMSNorm Fusion (`e9279b1`, `2df7638`, default ON)**:
   `AFF_FUSE_AR_RMSNORM=1` (default) enables `HasPreCollapse` in `tp_ar_batch_hc_expand_kernel` for narrow `nb == kNarrowTok == 16` batches when `shift_pre_` holds and the next layer is not Engram. The all-reduce expand kernel simultaneously computes `out_cur` (`sum_dst h_dst * pre_in_dst`) and partial squared reductions (`s_red_cur`, `s_red_hc`) into `b_hcp`, allowing `DenseGpu` to dispatch `batch_hc_norm_v41_only_hip` and `batch_hc_head_norm_only_hip` without re-running `hcn_v41_collapse_sq_kernel`.

5. **`R5` — Lossless 12.25-bit `bf16x12` Target LM Head (`e9279b1`, `2df7638`, default ON)**:
   `AFF_LMHEAD_BF16X12=1` (default whenever `AFF_LMHEAD_INT4=0`) packs the target `output` weight in `1024`-row chunks on load (`pack_bf16x12_hip`) into 32-column K-block SoA buffers (`b12_sm` 8-bit sign+mantissa, `b12_exp4` 4-bit exponent delta, `b12_mexp` per-32 max exponent) plus a host-built CSR escape table (`b12_esc_off`, `b12_esc_col`, `b12_esc_val`) for `±0.0`, subnormals, `±Inf/NaN`, or span `>= 15`. Decode runs via `matvec_bf16x12_multix_hip` (`nb <= 5`) and speculative verify/prefill via `batch_gemm_bf16x12_hip` (WMMA), decoding bit-identically to BF16 while freeing VRAM for **`+24` resident experts (`3,593 -> 3,617`)**.

6. **`R6` — Incremental SuffixDecoding Speculative Drafter + Depth Stop (`27d1402`, default ON)**:
   `aff::SuffixDraftIndex` (`src/engine/suffix_draft.h`) indexes token history incrementally with dual rolling hashes across four suffix lengths (`min_match..min_match+3`) and empirical transition probabilities (`D`, `expect = sum(D)`). Checked on CPU before `model.dspark_draft` (`AFF_DRAFT_SUFFIX=1`, `AFF_DRAFT_SUFFIX_MIN_MATCH=4`, `AFF_DRAFT_SUFFIX_MIN_SCORE=0.35`, `AFF_DRAFT_SUFFIX_MAX=12`, `AFF_DRAFT_SUFFIX_MIN_EXPECT=2.0`), it proposes up to `kSpecTok - 1 = 15` zero-GPU-draft tokens on recurring code/structured continuations while isolating `cost_ema` updates from suffix-hit steps. Companion `AFF_DRAFT_DEPTH_STOP=1` skips unhelpful DSpark calls (`7/8` cadence) when `surv_ema[1]` utility drops below `q=1` (`zero_run >= 2` when `AFF_SPEC_BACKOFF=0`).

7. **`R7` — Side-Band Infinity Cache Weight Prefetch (`e9279b1`, `2df7638`, `AFF_PREFETCH_BESIDE=0` default opt-in)**:
   Adds `Model::BatchOps::prefetch_hint` and optional extra CTAs (`AFF_PREFETCH_BLOCKS=16`, capped by `AFF_PREFETCH_MB=8`) inside `tp_ar_batch_hc_expand_kernel` to stream upcoming layer/shared-expert/head weights while waiting on peer flags. Locked OFF by default after ablation showed contention regressions on dual R9700 (`gfx1201`).
