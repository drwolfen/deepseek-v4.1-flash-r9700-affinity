## 1. Executive Summary

`v5.2.0` delivers paired VRAM reclamation, HIP decode/attention kernel fusion, host/tokenizer/prefix-cache throughput optimizations, and OpenAI SSE server queue hardening over `v5.1.2` (`8025372`):

- **Resident MoE Capacity (`+101` experts)**: Reclaiming dead V4.1 Q-RMS/compressor buffers and tiling Engram H2D/gather transfers frees **616 MiB/card** of scratch/Engram VRAM, expanding GPU-resident MoE capacity from **3,416 to 3,517 experts** (`+2.96%`) at identical `[355, 354] MiB` free VRAM (`0` OOM, `0` spill).
- **Decode & Warm Generation (`+6.8%` to `+56.1%`)**: Paired `bench_pp_tg.py` (`NGEN=192`) achieves **41.00–41.72 tok/s** warm Pass-2 decode across `l4k`/`l16k`/`l64k` (up from `26.72–31.42 tok/s`, **`+30.2%` to `+56.1%`**) and **21.33–38.74 tok/s** cold Pass-1 decode (`+6.8%` to `+42.0%`).
- **Prefill Throughput (`+5.2%` to `+12.6%`)**: Paired prefill improves across all depths (`597.0 tok/s` @4K Pass 1, `1,201.5 tok/s` @16K Pass 1, `1,325.8 tok/s` @64K Pass 1), while Gate 3(a) confirms async prefill tail leak elimination (`slot 0` vs client `gen_s` delta within `+0.09 s` to `+0.16 s`).
- **4-Prompt `temp=0.0` DSpark (`+14.4%` to `+17.3%`)**: All four prompts produce coherent, non-collapsed outputs with `+14.4%` to `+17.3%` streaming decode gains (`15.59–21.24 tok/s`).
- **Multi-Turn `64K -> 100K` Cached TTFT (`-47.0%` / `-55.9%`)**: Turn 2 (`80K` cached) TTFT drops from `2.049 s` to **`1.086 s` (`-47.0%`)**; Turn 4 (`123K` cached) TTFT drops from `2.386 s` to **`1.052 s` (`-55.9%`)**, with decode reaching `20.19 tok/s` (`+29.9%`).
- **OpenAI Queue Keepalive & Client-Disconnect Reclamation (`<= 1.13 s`)**: Concurrent FIFO slot queuing emits OpenAI-valid empty-delta SSE keepalives every `15.0 s`, and `fd_alive` disconnect probing drops closed queued clients within **`1.12 s`–`1.125 s`** (`0` tokens prefilled or decoded for disconnected requests).
- **Verification**: **4/4 GPU kernel suites PASS** (`0` HIP errors) and **9/9 CPU `ctest` suites PASS** (`0.29 s`).

## 2. Production Topology & Hard Safety Invariants

- **Dual Active Endpoints**: Port `:8000` (Docker container `deepseek-affinity`) and port `:8080` (local proxy forwarding `:8080 -> :8000`) serve identical `/health`, `/v1/models`, and `/v1/chat/completions` semantics. Containers run with `--security-opt label=disable` and `--ipc=host` for SELinux compatibility with `/dev/kfd` and `/dev/dri`.
- **Hard Safety Invariants Preserved**:
  - Target LM head remains BF16 (`AFF_LMHEAD_INT4` never enabled; `AFF_DRAFT_HEAD_INT4=1` retained).
  - `AFF_EQUAL_UBATCH=0` and `AFF_PREFETCH_RING=0` kept disabled.
  - MoE experts execute 100% on GPU (`0` CPU expert offload).
  - Live `kv_shrink_to` page unmapping remains forbidden.
  - `AFF_FP8_NARROW128` gate (`NEED_NARROW0=0`): default-on `kFKNarrow=128` specialization verified `+30.2%` to `+56.1%` faster on warm `tg2` than `v5.1.2`.

## 9. Summary of Engineering Changes (`v5.1.2` -> `v5.2.0`)

### Wave 1A: Server, Tokenizer, Prefix Cache & Host Pipeline (`45ea4eb`..`60676eb`)
- **HTTP Server & Slot Queue (`45ea4eb`, `f424cfd`, `34deb71`)**:
  - Added `fd_alive` socket liveness polling, strict FIFO slot queuing, and 15 s OpenAI-compatible empty-delta SSE keepalives while queued or during prefill heartbeats.
  - Wired `PrefillAlive` abort hook from server into `Model::forward_prefill` so disconnected clients abort mid-prefill without wasting GPU work.
  - Optimized streaming emit scans, depth-tracked DSML `<tool_call>`/`<antml:invoke>` close scanning, lock-free `/health` VRAM queries, and skipped unnecessary prefill logits.
- **Tokenizer & Chat Encode (`54c5d78`, `f424cfd`)**:
  - Added O(1) `decode_one` lookup, `added_lead` bitmask fast-path, BPE merge memoization, and turn-boundary longest-common-prefix (LCP) encode cache.
- **Prefix Cache & Engram (`d24e31d`)**:
  - Hardened delta checkpoint verification, added O(1) base block lookup, dynamic `hdr_buf` sizing, atomic prefix-cache index updates, and stack-allocated Engram temporaries.

### Wave 1B & 2B: HIP Kernels, VRAM Reclamation & Decode Pipeline (`79e8ac7`..`44e81ee`)
- **Indexer & FP8 Numerical Hardening (`79e8ac7`, `e626921`)**:
  - Fixed multi-token sparse indexer candidate stride and guarded invalid `<= k` entries.
  - Hardened FP8 GEMM boundary checks and made `Test 9` FP8 activation inputs E4M3-exact.
- **VRAM Reclamation & Engram Tiling (`b13cbf2`)**:
  - Omitted dead per-head Q-RMS scale buffers when `no_qrms_` (V4.1) and skipped compressor allocations on V4.1 non-KV-source layers, shrinking prefill arena (`-272 MiB/card`) and compressor+indexer (`-10 MiB/card`).
  - Tiled Engram transfers (`kEngramTileMax`) with H2D/gather overlap (`-334 MiB/card`), shifting `+614 MiB/card` into routed expert slabs (`3,416 -> 3,517` resident experts).
- **HIP Decode Kernel Fusion & Specialization (`3f24d07`, `edba510`)**:
  - Fused `attn_out` transpose + inverse RoPE tail + optional FP8 QDQ (`AFF_FUSED_ATTN_OUT_PREP`, default on).
  - Specialized `kFKNarrow=128` FP8 multi-GEMM (`AFF_FP8_NARROW128`, default on), added `AFF_REUSE_NORM_Q8` (default on) to reuse normalized Q8 activations, and consolidated draft confidence readout into a single drain.
  - Added `PrefillAlive` abort checks, host scratch reuse, and V4.1 collapse / replay sync fixes.
- **Wave 2B Final Polish (`44e81ee`)**:
  - Skipped `ThreadPool` dispatch overhead on small (`live < 64`) decode Engram gathers, clamped `EngramBgWorker` threads to Linux `sched_getaffinity` cpuset cores, synchronized prefill devices unconditionally before decode timing (`dense_gpu.sync_devices()`), and gated `kFKNarrow=128` behind `AFF_FP8_NARROW128`.
