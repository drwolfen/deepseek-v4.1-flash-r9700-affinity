## 2. Shipped Bug Fixes & Wave 10A Changes (`1676e05`)

### 2.1 Bug Fixes (`BUG-1`, `BUG-2`, `~DenseGpu()`, `BUG-5`, `BUG-6`, `BUG-7`)

1. **`BUG-1` — Multi-`n_expert` Router Bias Stride Isolation (`src/gpu/dense_gpu.hip`)**:
   - `router_scratch()` now allocates `D.b_rbias` with uniform `r_bias_stride = std::max(r_max_expert_, n_expert)` instead of layer 0's `n_expert`, and `batch_router_topk()` guards `if (n_expert > D.r_bias_stride) return false;` before indexing `D.b_rbias + (size_t)h * D.r_bias_stride`. This stops DSpark stages (`h=40..42`, `n_expert=128`) from overwriting target layers 13 and 14 router biases (`n_expert=384`).
2. **`BUG-2` — Draft Router Tensor Sizing & Per-Call Banding (`src/engine/model.cpp`, `src/gpu/dense_gpu.hip`)**:
   - `bind_layer_common()` now derives `ne = (rg && rg->desc.rows) ? (uint32_t)rg->desc.rows : cfg.n_expert` when reading/registering `ffn_gate_inp` (`128` for draft stages rather than `cfg.n_expert = 384`), eliminating the `2.50 MiB` (`2.62 MB`) host `mmap` over-read.
   - `reg_router()`, `router()`, and `batch_router()` compute `router_band(...)` per call and size `D.d_rlog` dynamically via `d_rlog_cap` so target (`384`) and draft (`128`) routers never alias stale `router_rows`.
3. **`~DenseGpu()` & `idx_grow()` Pointer/Pinned-Memory Fixes (`src/gpu/dense_gpu.hip`)**:
   - Avoids calling `hipFree`/`hipHostFree` on interior slice pointers `b_rwt`/`b_rn` (`b_rsel`) and `h_rwt`/`h_rn` (`h_rsel`), frees missing `b_conf`/`b_hcp` device buffers, and frees host-pinned `hi_w`/`hi_nc`/`hi_ncb` with `hipHostFree` in both `~DenseGpu()` and `idx_grow()`.
4. **`BUG-5` — Dynamic Per-Block Repeat Penalty (`tools/affinity.cpp`)**:
   - Adds `refresh_penalty_ids()` (`AFF_REPEAT_PENALTY_DYNAMIC=1` default ON, `"0"` restores static snapshot) per decode verify block and exempts `eos`, `think_marker_ids`, and `dry_exempt_ids` (DSML tool markup tokens) from repeat penalties.
5. **`BUG-6` — Think-Scoped Prompt-Verbatim DRY Guard (`tools/affinity.cpp`)**:
   - Gates DRY's `2x` prompt-verbatim threshold (`need * 2`) with `!in_think` (`budget && !budget->settled()`), preventing prompt-seeded mantra echoes inside `<think>` from bypassing normal `dry_min_repeats` enforcement.
6. **`BUG-7` — Short-Scale Loop & Short-Window Novelty Breakers (`src/engine/thinking_budget.h`, `tools/affinity.cpp`, `tests/test_thinking_budget.cpp`)**:
   - Adds a sliding short-window bigram diversity detector (`short_low_novelty`: `AFF_THINK_SHORT_NOVELTY_WINDOW=128`, `AFF_THINK_SHORT_NOVELTY_MIN_TOKENS=160`, `AFF_THINK_SHORT_NOVELTY_MIN=0.20`), tunes short-loop defaults (`AFF_THINK_SHORT_LOOP_SPAN=16`, `AFF_THINK_SHORT_LOOP_REPEATS=3`, `AFF_THINK_SHORT_LOOP_WINDOW=1024`), keeps long novelty defaults (`AFF_THINK_NOVELTY_WINDOW=512`, `AFF_THINK_NOVELTY_MIN_TOKENS=1024`, `AFF_THINK_NOVELTY_MIN=0.28`), and sets `AFF_THINK_FREEZE_DISTINCT=56`.

### 2.3 Empirically Withheld Candidates (`PCIe #5` & `StageRing::fit` Hysteresis)

Three prefill-path candidates evaluated on pre-release builds were **cleanly reverted before `1676e05`** after paired server benchmarking exposed host/GPU queue regressions:

- Skipping `D.ncomp` H2D or switching to ring-buffered `D.inc`/`D.incb` under `flash && gather` removed host throttling against ROCm's single HW queue (`GPU_MAX_HW_QUEUES=1`), causing the host to queue 40 layers deep before stalling for `1.66 s` at `D.eng.wait()` and dropping untraced server `l64k` prefill by `-2.0%` to `-4.6%` (`1372.0–1375.8 tok/s` vs `1402.0–1405.8 tok/s` after revert).
- `StageRing::fit` 4× shrink hysteresis added `512 KiB/card` pinned retention without net win and was reverted alongside the `D.ncomp` changes, leaving zero prefill hot-path code differences between `v5.6.1` (`1493e23`) and `v5.6.2` (`1676e05`).
